Jesus The Way Ministry Website

Welcome to the official repository for the  Jesus The Way Ministry website! This website is designed to provide information about our church, share sermons, announce events, and connect with our community.

About the Project

This website is a responsive, user-friendly platform built to serve the members of Jesus The Way Ministry and anyone interested in learning more about our faith and community. It includes the following features:

- Homepage: Welcome message, upcoming events, and quick links.
- About Us: Church history, mission, and staff information.
- Sermons: Audio/video recordings of past sermons.
- Events Calendar: Upcoming services, Bible studies, and community events.
- Donations: Online giving options.
- Contact Page: Location, service times, and a contact form.
- Blog/News: Updates, devotionals, and announcements.

Technologies Used

- HTML5: For structuring the website.
- CSS3: For styling and responsiveness.
- Bootstrap 5: For pre-built components and responsive design.
- JavaScript: For interactivity (optional).
- GitHub Pages: For hosting the website.
